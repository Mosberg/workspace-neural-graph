# Contributing Guide

Thank you for your interest in contributing to Workspace Neural Graph!

## Development Workflow

1. Fork the repository and create your branch from `main`:
   ```bash
   git checkout -b feature/my-new-feature

```

2. Ensure dependencies are installed:
```bash
npm install

```


3. Run the linter and tests:
```bash
npm run lint
npm test

```


4. Commit your changes using conventional commit messages:
```text
feat: add support for python import statement parsing
fix: resolve broken zoom scale boundary on 4k displays

```


5. Push to your fork and submit a Pull Request.

## Pull Request Guidelines

* Keep changes focused and atomic.
* Update documentation for user-facing features.
* Verify your changes across both light and dark VS Code themes.
